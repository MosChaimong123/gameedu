# Civilization Idle Phase 5: Space Age

วันที่ตรวจสอบ: 27 พฤศจิกายน 2026

## ขอบเขตที่ทำเสร็จ

- เพิ่มยุคอวกาศและการเปลี่ยนยุคหลังวิจัยวิทยาศาสตร์อวกาศ
- เพิ่มทรัพยากร โลหะผสมขั้นสูง เชื้อเพลิงยาน และชิ้นส่วนยาน
- เพิ่มคลังวัสดุอวกาศ ศูนย์ทดสอบยาน และท่าอพยพ
- เพิ่มงานวิจัยหลัก 6 งาน พร้อมข้อความประโยชน์และค่าที่เปลี่ยนทั้งไทย/อังกฤษ
- เพิ่มโรงงานวัสดุอวกาศ โรงกลั่นเชื้อเพลิงยาน และอู่ประกอบวงโคจร
- เพิ่มวิจัยต่อยอดประสิทธิภาพวัสดุและระบบขับดัน สูงสุดอย่างละ 5 ระดับ
- เพิ่มโครงการยานอพยพ 4 ขั้น: โครงยาน ระบบขับดัน ระบบยังชีพ และเตรียมอพยพ
- ขั้นสุดท้ายต้องมีท่าอพยพ กำลังไฟอย่างน้อย 12 กำลังประมวลผลอย่างน้อย 4 และเชื้อเพลิงตามต้นทุนหลังส่วนลด
- เมื่อขั้น 4 สำเร็จ ระบบตั้ง `spaceCompleted=true` แต่ไม่รีเซ็ตเมืองอัตโนมัติ การเลือกรางวัลและเริ่มรอบใหม่อยู่ใน Phase 6
- เพิ่ม schema/content v5 และ migration ต่อเนื่องจาก v1-v4 โดยเติมข้อมูลยุคอวกาศแบบไม่เปลี่ยนเซฟเดิม
- เพิ่ม Hero เมืองท่าอวกาศ Preview, milestone และ state inspection สำหรับ browser QA

## สมดุลเริ่มต้น

- โรงงานวัสดุอวกาศ: เหล็กกล้า 0.2 + สำริด 0.1 + ไฟ 2 -> โลหะผสม 0.1/วินาที
- โรงกลั่นเชื้อเพลิงยาน: ถ่านหิน 0.2 + ไฟ 2 -> เชื้อเพลิง 0.1/วินาที
- อู่ประกอบวงโคจร: โลหะผสม 0.1 + วงจร 0.05 + ไฟ 3 -> ชิ้นส่วนยาน 0.06/วินาที
- ขั้น 1: โลหะผสม 500 + ชิ้นส่วน 250
- ขั้น 2: ชิ้นส่วน 350 + เชื้อเพลิง 600 และต้องมีศูนย์ทดสอบ
- ขั้น 3: วงจร 200 + ข้อมูล 400 + อาหาร 300
- ขั้น 4: เชื้อเพลิง 800, ลด 2% ต่อระดับวิจัยระบบขับดัน สูงสุดลด 10%
