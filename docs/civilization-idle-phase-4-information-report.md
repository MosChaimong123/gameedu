# Civilization Idle Phase 4: Information Age

วันที่ตรวจสอบ: 27 พฤศจิกายน 2026

## ขอบเขตที่ทำเสร็จ

- เพิ่มยุคข้อมูลข่าวสารและการเปลี่ยนยุคหลังวิจัยระบบโรงงานอัตโนมัติ
- เพิ่มทรัพยากร วงจร ข้อมูล และกำลังประมวลผล
- เพิ่มกิจกรรมตรวจระบบ อาคารยุคข้อมูล 3 แบบ งานวิจัยหลัก 8 งาน และวิจัยต่อยอด 2 แบบ
- เพิ่มสายประกอบวงจร ศูนย์ข้อมูล และห้องวิจัยดิจิทัล
- เพิ่มกำลังประมวลผลแบบไม่เก็บสะสม ศูนย์ข้อมูลต้องมีไฟและวัตถุดิบจึงจ่าย Compute ได้
- เพิ่มกฎอัตโนมัติฝั่งเซิร์ฟเวอร์ 3 แบบ: สำรองทองแดง 40, สำรองเหล็กกล้า 50 และให้ศูนย์ข้อมูลรับไฟก่อน
- ช่องกฎเริ่มที่ 1 หลังวิจัยการจัดตารางงาน และเพิ่มจากศูนย์จัดตารางได้สูงสุด 3 ช่อง
- เพิ่มเงื่อนไขจบยุค: โรงงานดิจิทัลครบ 3 แบบ วงจร 100 ข้อมูล 200 Compute อย่างน้อย 2 และวิจัยวิทยาศาสตร์อวกาศ
- เพิ่มการย้ายเซฟอัตโนมัติจาก schema v1/v2/v3 เป็น v4
- เพิ่ม Hero ยุคข้อมูลข่าวสาร, Preview และ UI ภาษาไทย/อังกฤษสำหรับระบบใหม่

## สมดุลเริ่มต้น

- สายประกอบวงจร: ใช้ทองแดง 0.2 เหล็กกล้า 0.1 และไฟ 1 ผลิตวงจร 0.12/วินาที
- ศูนย์ข้อมูล: ใช้วงจร 0.05 และไฟ 2 ผลิตข้อมูล 0.15/วินาที พร้อม Compute 2
- ห้องวิจัยดิจิทัล: ใช้ข้อมูล 0.1 และ Compute 1 ผลิตความรู้ฐาน 0.2/วินาที
- สถานีเครือข่ายเพิ่มกำลัง Compute 5% ต่อหลัง
- การบีบอัดข้อมูลเพิ่มผลผลิตข้อมูล 3% ต่อระดับ สูงสุด 5 ระดับ
- ประสิทธิภาพคอมพิวเตอร์ลดการใช้ไฟของระบบดิจิทัล 2% ต่อระดับ สูงสุด 5 ระดับ

## การตรวจสอบ

- Focused engine, migration, persistence และ UI contract tests: 61 ผ่าน
- ครอบคลุมวงจรผลิตต่อเนื่อง ไฟ Compute การพักโรงงานตาม reserve ช่องกฎ และเงื่อนไขจบยุค
- TypeScript: ผ่าน
- ESLint เฉพาะไฟล์ที่แก้: ผ่าน
- Architecture check: ผ่าน
- Production build: ผ่าน
- Desktop browser QA: ผ่าน โดยตรวจโครงข่ายไฟฟ้า Compute และการเปิดกฎอัตโนมัติจาก 1/2 เป็น 2/2 ช่อง
- Mobile browser QA ที่ 390x844: ผ่าน การ์ดและปุ่มไม่ล้นจอ แถบทรัพยากรปัดและ snap ได้โดยซ่อน scrollbar
- `render_game_to_text`: อ่าน era, resources, converters, automation rules และสถานะจบยุคได้ครบ
- หมายเหตุ: Playwright แบบ standalone พบเฉพาะ Socket.IO localhost:3001 ที่ไม่ได้เปิด ซึ่งเป็นบริการพัฒนาแยกและไม่ใช่ข้อผิดพลาดของ Civilization

## งานที่ยังไม่ถือว่าปิด

- เป้าหมายเวลาเล่นยุคข้อมูลข่าวสารประมาณ 125 ชั่วโมงต้องเก็บ telemetry จาก Staging Pilot
- Phase นี้ยังไม่เพิ่มยุคอวกาศหรือระบบรีเซ็ตรอบใหม่
- ยังไม่เปิด feature flag, ไม่เขียน Production database และไม่ deploy Production
