# Civilization Idle: แบบเกมละเอียด 5 ยุค

สถานะ: ร่างออกแบบเพื่ออนุมัติและทดสอบสมดุล | 25 พฤศจิกายน 2026

อ่านร่วมกับ [แผน 500 ชั่วโมง](./civilization-idle-500-hour-roadmap.md) และ [ตารางตัวละคร 20 ตัว](./civilization-idle-city-leaders-catalog.md). **ตอนนี้ engine มีเพียงยุคหินกับสำริด**; เนื้อหายุค 3-5 และการขยายระดับในเอกสารนี้ยังไม่ใช่ฟีเจอร์ที่เล่นได้จริง. ค่าใหม่ทั้งหมดเป็นสมมติฐานให้ simulation และ pilot พิสูจน์ก่อน implement

## เป้าหมายของหนึ่งรอบ

เริ่มชุมชนยุคหิน -> จัดอาหาร/คน/คลัง -> ผลิตโลหะ -> ขับเคลื่อนเครื่องจักร -> ใช้ข้อมูลและ automation -> ประกอบยานและอพยพ -> **เลือกรางวัลถาวร 1 ชิ้น** -> ยืนยันรีเซ็ตเป็นรอบใหม่. รอบแรกค่ากลางเป้าหมาย ~500 ชั่วโมงตามปฏิทิน (หิน 45, สำริด 75, อุตสาหกรรม 105, ข้อมูล 125, อวกาศ 150); ผู้เล่นเก่ง/สบาย ๆ อาจต่างกันมาก. ไม่ตั้ง timer บังคับและไม่ยืดเกมด้วยการคูณราคาอย่างเดียว

## กติกาเศรษฐกิจร่วม

- Resource แบบ **คลัง** มี `amount/cap`; resource แบบ **กำลังผลิต** เช่นไฟฟ้า/พลังประมวลผล มีอัตรา `supply/demand` ต่อวินาทีและไม่ควรค้างสะสมข้าม offline โดยไม่มีกติกาแบตเตอรี่/คิวงาน
- คนงานผลิตจาก `จำนวน * อัตราพื้นฐาน * (1 + โบนัสที่ใช้ได้)`; ประชากรกินอาหารตามกติกา. แสดง gross, consumption, net, ETA เต็ม/หมด และเหตุผลหยุดโรงงาน
- โรงงานกิน input และสร้าง output แบบ all-or-nothing ต่อช่วงจำลอง; ไม่หัก input ถ้า output เต็มหรือพลังงานไม่พอ. ลำดับโรงงานใช้ input ที่ขาดแคลนต้องแน่นอนและแสดงให้ผู้เล่นเลือก priority ในยุคที่ปลดล็อก
- ราคาอัปเกรดชนิดใหม่เสนอ `floor(baseCost * growth^level)` แยก resource, growth ราว 1.12-1.30 ตามบทบาท. ต้องมี cap เพียงพอสำหรับซื้อระดับถัดไป; bonus เพิ่มแบบค่อยเป็นค่อยไป, ไม่ใช่ exponential power
- ไม่มีตัวละครหรือแต้มจากงานเป็นเงื่อนไขผ่านยุค. ตัวละครช่วยเลือกสายเล่นเท่านั้น; โบนัสซ้อนตามกติกาใน catalog ตัวละคร
- ค่ากิจกรรม/งาน/อาคาร/วิจัยยุคหิน-สำริดที่ระบุว่า **ปัจจุบัน** มาจาก engine; ระดับที่เสนอสูงกว่าเดิมต้องปรับ schema/version และทดสอบเซฟเก่า

## 1. ยุคหิน: สร้างเมืองที่เลี้ยงตัวเองได้ (เป้า 0-45 ชม.)

**วงจร:** กดเก็บอาหาร/ไม้/หิน -> จัดคนงาน -> เพิ่มคลัง/ที่อยู่ -> ปลดนักปราชญ์ -> วิจัย 3 แขนง -> เกษตรกรรม. ทางเลือกหลักคืออาหารเพื่อประชากร, วัสดุเพื่ออาคาร หรือความรู้เพื่อไปยุคเร็ว; อาหารสุทธิต้องเห็นชัด

| องค์ประกอบ | มีอยู่ปัจจุบัน | การขยายที่เสนอ / ระดับสูงสุด |
| --- | --- | --- |
| กิจกรรม | เก็บผลไม้, ตัดไม้, กะเทาะหิน ระดับ 1-5 | ขยายเป็น 1-10; Lv6 เพิ่ม reward ทางเลือก, Lv8 ลด cooldown ถึง floor, Lv10 เพิ่มผลต่อการกดครั้งแรกหลัง offline โดยไม่ auto-repeat |
| อาคาร | เพิงพัก, ยุ้งฉาง, ลานกองวัสดุ สร้างซ้ำได้; ลานล่า/เหมือง/ลานเล่านิทานอย่างละ 1 | เพิงพักสูงสุด 20, ยุ้งฉาง 10, ลานวัสดุ 10; อาคารปลดงานคงระดับ 1 เพื่อไม่ซื้อซ้ำไร้ความหมาย |

## 2. ยุคสำริด: จัดโซ่โลหะ (เป้า 45-120 ชม.)

**วงจร:** หาแร่ทองแดง -> เตาถลุง -> โรงหล่อสำริด -> เหล็ก -> วิจัยการเขียนและพลังไอน้ำ. ผู้เล่นเลือกระหว่างลงทุนคลัง, วิจัย หรือเพิ่ม throughput; โรงงานที่ input ขาดต้องหยุดโดยไม่เสียของ

| องค์ประกอบ | มีอยู่ปัจจุบัน | การขยายที่เสนอ / ระดับสูงสุด |
| --- | --- | --- |
| กิจกรรม | ร่อนทองแดง, ตีเหล็ก ระดับ 1-5 | ขยายเป็น 1-10 เช่นยุคหิน; ไม่ทำให้กดมือชนะโรงงานที่จัดดี |
| อาคาร | บ้านอิฐดินเผา +4 population cap/หลัง, คลังโลหะ +300 cap โลหะ/หลัง | บ้านสูงสุด 15, คลังสูงสุด 10; ตัวเลข cap ใหม่ทดสอบ affordability |
| โรงงาน | เตาทองแดง 0.5 ไม้ -> 0.4 ทองแดง/s; โรงหล่อ 0.5 ทองแดง+0.3 ไม้ -> 0.3 สำริด/s; เตาเหล็ก 0.8 ไม้+0.2 หิน -> 0.3 เหล็ก/s | ปัจจุบันจำนวนโรงงาน (`count`) ขยายกำลังผลิตและราคาตามจำนวน; เสนอ max 15 ต่อชนิด, UI เรียกเป็นระดับ/จำนวนอย่างสม่ำเสมอ, เพิ่ม priority input เมื่อจำเป็น |
| milestone | Steam Power ทำเครื่องหมายเนื้อหาสำริดจบ | ผลิตโลหะทั้ง 3, โรงงาน Lv3 แรก, เหล็กสุทธิพอ, พลังไอน้ำ |

| --- | ---: | --- | --- |
| การถลุง | 200 | เกษตรกรรม | เปิดเตาถลุงทองแดง |
| งานสำริด | 300 | การถลุง | เปิดโรงหล่อสำริด |
| งานเหล็ก | 400 | งานสำริด | เปิดเตาหลอมเหล็ก |
| การเขียน | 250 | เกษตรกรรม | ผลิตความรู้ passive +50% |
| พลังไอน้ำ | 800 | งานเหล็ก+การเขียน | ทำเครื่องหมายจบสำริดปัจจุบัน |

**วิจัยเพิ่มที่เสนอ:** การหล่อแม่นยำ 3 ระดับ (ลด input โรงหล่อ 2%/ระดับ), การสำรองโลหะ 3 ระดับ (+5% cap โลหะ/ระดับ). ในแบบห้ายุค พลังไอน้ำเป็น prerequisite ของอุตสาหกรรม แต่ต้องเพิ่ม command/era transition ใหม่; ยังไม่ปลดล็อกจริง

## 3. ยุคอุตสาหกรรม: พลังงานและเครื่องจักร (เป้า 120-225 ชม.)

**ระบบใหม่:** supply/demand ไฟฟ้าและ priority โรงงาน. ถ้าไฟฟ้าไม่พอ โรงงาน priority ต่ำหยุดก่อน ไม่แบ่งไฟจนทุกโรงงานผลิตครึ่ง ๆ แบบที่ UI อธิบายยาก. ถ่านหินเป็นคอขวดแรก; เหล็กกล้าเป็นสะพานไปวงจร/ยาน

| สิ่งปลูกสร้าง/สายผลิต | input -> output (อัตรา baseline เสนอ) | ระดับสูงสุด | จุดตัดสินใจ |
| --- | --- | ---: | --- |
| เหมืองถ่านหิน | คนงาน 1 -> ถ่านหิน 0.25/s | 15 | ย้ายแรงงานจากอาหาร/วิจัย |
| โรงเหล็กกล้า | เหล็ก 0.4 + ถ่านหิน 0.2 -> เหล็กกล้า 0.25/s | 15 | เลือกสำรองเหล็กหรือเร่งเหล็กกล้า |
| เครื่องกำเนิดไฟฟ้า | ถ่านหิน 0.3 -> ไฟฟ้า 2 หน่วยกำลังผลิต | 15 | ใช้ถ่านหินเพื่อไฟหรือเหล็กกล้า |
| โรงเครื่องจักร | เหล็กกล้า 0.25 + ไฟฟ้า 1 -> ชิ้นส่วนเครื่องจักร 0.15/s | 15 | ลด bottleneck พลังงาน/วัสดุ |
| อาคาร | บ้านแรงงาน, คลังอุตสาหกรรม, สถานีไฟฟ้า | 15 / 10 / 10 | ประชากร/คลัง/กำลังผลิต |

**วิจัยเสนอ (ต้นทุนความรู้ยังต้อง balance):** ธรณีวิทยาถ่านหิน -> เตาเหล็กกล้า -> เครื่องจักรไอน้ำ -> การผลิตไฟฟ้า -> ระบบสายพาน -> การจัดลำดับโรงงาน -> เครื่องกำเนิดประสิทธิภาพสูง -> **ระบบโรงงานอัตโนมัติ**. วิจัยสายพานเปิด priority; การผลิตไฟฟ้าเปิด supply/demand; วิจัยขั้นสุดท้าย + ชิ้นส่วนเครื่องจักรครบเป็นเงื่อนไขเข้ายุคข้อมูล ไม่ต้องรอเวลาเฉย ๆ

อัปเกรดวิจัยซ้ำ: ประสิทธิภาพเชื้อเพลิง Lv1-5 (-2% input ถ่านหิน/ระดับ) และประสิทธิภาพเครื่องจักร Lv1-5 (+3% output/ระดับ); cap รวมส่วนลด 30%. กิจกรรมกดเองสำหรับขุดถ่านหิน Lv1-10 เป็นทางกู้เมื่อติดขัด ไม่ใช่แหล่งหลักระยะยาว

## 4. ยุคข้อมูลข่าวสาร: ออกแบบ automation (เป้า 225-350 ชม.)

**ระบบใหม่:** วงจร -> ศูนย์ข้อมูลที่ใช้ไฟ -> ข้อมูลและกำลังประมวลผล. ผู้เล่นเลือกกฎ automation ได้จำกัด เช่น พักโรงงานเมื่อ input ต่ำกว่า reserve, ให้ไฟฟ้ากับโรงงานสำคัญก่อน. กฎทำงานฝั่งเซิร์ฟเวอร์แบบ deterministic ใน sync เดียว ไม่ซื้อวิจัย/ตัวละคร/รีเซ็ตแทนผู้เล่น

| สิ่งปลูกสร้าง/สายผลิต | input -> output baseline เสนอ | ระดับสูงสุด | จุดตัดสินใจ |
| --- | --- | ---: | --- |
| โรงประกอบวงจร | ทองแดง 0.2 + เหล็กกล้า 0.1 + ไฟฟ้า 1 -> วงจร 0.12/s | 15 | แย่งเหล็กกล้ากับเครื่องจักร |
| ศูนย์ข้อมูล | วงจร 0.05 + ไฟฟ้า 2 -> ข้อมูล 0.15/s + พลังประมวลผล 2 | 15 | สมดุลข้อมูล/ไฟฟ้า/วงจร |
| ห้องวิจัยดิจิทัล | ข้อมูล 0.1 + พลังประมวลผล 1 -> ความรู้ 0.2/s | 15 | ใช้ข้อมูลวิจัยหรือเก็บโครงการ |
| อาคาร | คลังอิเล็กทรอนิกส์, สถานีเครือข่าย, ศูนย์คิวงาน | 10 / 10 / 5 | cap/กำลังประมวลผล/จำนวนกฎ |

**วิจัยเสนอ:** วงจรไฟฟ้า -> คอมพิวเตอร์ -> เครือข่าย -> ระบบฐานข้อมูล -> การจัดคิวงาน -> การจำลองเชิงคำนวณ -> การสื่อสารระยะไกล -> **วิทยาศาสตร์อวกาศ**. วิจัยคิวงานเปิดกฎ automation 1 ช่อง; เพิ่มผ่านอาคาร/วิจัยสูงสุด 3 ช่อง ไม่เกิดกฎที่จ่ายทรัพยากรฟรี

อัปเกรดซ้ำ: การบีบอัดข้อมูล Lv1-5 (+3% ข้อมูล/ระดับ), ประสิทธิภาพคอมพิวเตอร์ Lv1-5 (-2% demand ไฟ/ระดับ). กิจกรรมกดเอง: ตรวจระบบ/เก็บข้อมูลเฉพาะกิจ Lv1-10 แต่ไม่สามารถข้าม requirement ชิ้นส่วน. เข้ายุคอวกาศเมื่อมีงานวิจัยปลายยุค + โครงข่าย/ชิ้นส่วนเริ่มต้นครบ

## 5. ยุคอวกาศ: โครงการอพยพ (เป้า 350-500 ชม.)

**ระบบใหม่:** สร้างยานเป็นโครงการ 4 ขั้นที่ต้องเลือกวางกำลังผลิต ไม่ใช่ progress bar เดียว. โรงงานโลหะเก่า, ไฟฟ้า และวงจรยังมีบทบาท; ผู้เล่นเลือกลงทุนเร่งวัสดุ, เชื้อเพลิง, ชิ้นส่วน หรือวิจัยระบบยาน

| สิ่งปลูกสร้าง/สายผลิต | input -> output baseline เสนอ | ระดับสูงสุด | จุดตัดสินใจ |
| --- | --- | ---: | --- |
| โรงวัสดุอวกาศ | เหล็กกล้า 0.2 + สำริด 0.1 + ไฟฟ้า 2 -> โลหะผสม 0.1/s | 15 | ดูแลโซ่โลหะสองยุค |
| โรงเชื้อเพลิงยาน | ถ่านหิน 0.2 + ไฟฟ้า 2 -> เชื้อเพลิงยาน 0.1/s | 15 | แย่งพลังงานกับโรงวัสดุ |
| อู่ประกอบ | โลหะผสม 0.1 + วงจร 0.05 + ไฟฟ้า 3 -> ชิ้นส่วนยาน 0.06/s | 15 | บริหาร 3 คอขวดพร้อมกัน |
| อาคาร | คลังวัสดุอวกาศ, ศูนย์ทดสอบ, ท่าอพยพ | 10 / 5 / 1 | cap/ช่องทดสอบ/ปลายเกม |

**วิจัยเสนอ:** วัสดุเบา -> ระบบขับดัน -> การนำทาง -> ระบบยังชีพ -> การทดสอบยาน -> การอพยพ. วิจัยซ้ำ: ประสิทธิภาพวัสดุ Lv1-5 (-2% input โลหะผสม/ระดับ), ระบบขับดัน Lv1-5 (-2% เชื้อเพลิงทดสอบ/ระดับ). ทุกผลมีเพดานรวมและไม่ลด input เป็นศูนย์

| โครงการยาน | สิ่งที่ต้องสะสม/ทำ | ผลเมื่อเสร็จ |
| --- | --- | --- |
| 1. โครงยาน | โลหะผสม+ชิ้นส่วน | เปิดการทดสอบเครื่องยนต์ |
| 2. ระบบขับดัน | ชิ้นส่วน+เชื้อเพลิง | เปิดการนำทาง |
| 3. ระบบนำทางและยังชีพ | วงจร+ข้อมูล+อาหารสำรอง | เปิดทดสอบสุดท้าย |
| 4. ทดสอบและอพยพ | ไฟฟ้า/พลังประมวลผลพอ, เชื้อเพลิงสำรอง, วิจัยครบ | หน้า preview รางวัลถาวร 1 จากหลายตัวเลือก |

ปริมาณวัสดุของแต่ละขั้นต้องได้จาก simulator ไม่ตั้งตัวเลขคงที่ก่อนพิสูจน์ว่า 500 ชั่วโมงเป็นผลจากกลยุทธ์จริง. การกดอพยพ **ไม่รีเซ็ตทันที**; preview แสดงสิ่งที่หาย/คงอยู่และรางวัลหนึ่งชิ้น, กดยืนยันสองขั้น แล้ว server บันทึก reward + รอบใหม่ atomically. ตัวละคร/ระดับ/แต้มพิเศษเมืองคงอยู่ตาม catalog

## สิ่งที่แนะนำเพิ่มให้สนุกและไม่เหนื่อย

1. **เป้าหมายใกล้/ไกล:** แต่ละยุคมี 6-10 milestone ที่บอกขั้นถัดไปและเหตุผล; milestone เป็นคำแนะนำ ไม่บังคับลำดับเดียว
2. **มุมมองสายผลิต:** แสดง input -> output และคอขวดเป็นภาพ/ข้อความ; กดจากทรัพยากรไปโรงงานหรือวิจัยที่เกี่ยวข้องได้ทันที
3. **เปรียบเทียบก่อนซื้อ:** อาคาร/โรงงาน/วิจัย/ตัวละครแสดงต้นทุน, ผลผลิตสุทธิก่อน-หลัง และเวลาคืนทุนโดยประมาณเมื่อคำนวณได้
4. **เหตุการณ์เมืองแบบเลือกได้:** ผูกกับ milestone จริง ไม่สุ่มลงโทษแรง; เช่น วิจัยใหม่เปิดตัวเลือกแก้คอขวดสองแนว, ผลไม่ถาวรเกินไป
5. **ภาพเมืองตามความก้าวหน้า:** เปลี่ยนเฉพาะจุดสำคัญของแต่ละยุค, มี fallback และไม่เพิ่มภาระโหลดมือถือมาก
6. **สรุป offline:** สิ่งที่ผลิตได้, เวลาที่ระบบหยุดเพราะ input/cap, milestone ที่ผ่าน, สิ่งที่ควรทำต่อ; ไม่บังคับกลับมาเล่นทุก 8 ชั่วโมง
7. **สมุดบันทึกเมืองส่วนตัว:** แสดงการตัดสินใจและเวลาจบแต่ละยุคเพื่อเทียบรอบใหม่ ไม่จัดอันดับนักเรียนหรือผูกคะแนนเรียน

## การพิสูจน์สมดุลก่อนสร้างจริง

- ทำ balance sheet/agent simulation ของอย่างน้อย 4 กลยุทธ์: อาหาร-ประชากร, วิทยาศาสตร์, โรงงาน, สมดุล; ทดสอบไม่มีตัวละคร/ตัว Lv1/Lv5, offline 24-72 ชั่วโมง, อาหารหมด, input ไม่พอ, cap เต็ม และหลายหน้าต่าง
- ค่ากลางรอบแรกเป้า 400-600 ชั่วโมงจาก pilot หลังข้อมูลพอ; fast route ไม่ต่ำมากเพราะ exploit, slow route ไม่ softlock. ถ้าผู้เล่นแค่รอโดยไม่มีทางเลือก 3 session ติดกัน ต้องแก้ระบบ ไม่เพิ่มราคา
- ก่อนเพิ่มยุคใหม่ทุกครั้งต้องเขียน content catalog, formulas, invariants, migration, locale TH/EN, unit/integration tests, visual QA มือถือ และ staging pilot. Engine/เวลา/ต้นทุนอยู่ฝั่ง server; client ไม่ส่งยอดทรัพยากรไปทับเซฟ
- เพดาน offline 8 ชั่วโมงปัจจุบันไม่เหมาะกับเป้า 500 ชั่วโมง; ออกแบบใหม่และ benchmark การจำลองหลายวันก่อนเปิดยุคยาว โดยไม่สูญเสียทรัพยากรที่สะสมเมื่อไม่ได้เข้าเกม
- ทดสอบ storage affordability: ผู้เล่นต้องสามารถเพิ่ม cap จนพอจ่ายราคาอัปเกรด/วิจัยปลายยุค; เช็ก number precision ก่อนเพิ่ม resource จำนวนมาก

## ลำดับตัดสินใจและลงมือ

1. ยืนยันชื่อทรัพยากร/ธีมการศึกษา, ความหมายของไฟฟ้าและพลังประมวลผล, และ 500 ชั่วโมงเป็นค่ากลางรอบแรก
2. วัด pacing สองยุคที่มีอยู่ แล้วออกแบบ balance sheet พร้อมต้นทุนจริงต่อ node/ระดับ; ตัวเลขอัตรายุค 3-5 ข้างบนยังเป็น baseline ไม่ใช่ final
3. ปรับ offline, net-rate UI และเซฟก่อนเพิ่มเนื้อหา; จากนั้นขยาย Stone/Bronze อย่างระมัดระวังและทำ migration
4. สร้าง Industrial -> Information -> Space ตามลำดับ โดยให้แต่ละยุคเล่นจบและทดสอบได้ก่อนเริ่มยุคถัดไป
5. ทำ Prestige/รางวัลหนึ่งชิ้นหลังโครงการอวกาศใช้ได้จริง; pilot ทั้งรอบแรกก่อนเปิด production
