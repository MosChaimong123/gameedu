# Civilization Idle Phase 3: Industrial Age
วันที่ตรวจสอบ: 26 พฤศจิกายน 2026

## ขอบเขตที่ทำเสร็จ

- เพิ่มยุคอุตสาหกรรมและการเปลี่ยนยุคหลังวิจัยพลังไอน้ำ
- เพิ่มทรัพยากร ถ่านหิน เหล็กกล้า ไฟฟ้า และเครื่องจักร
- เพิ่มกิจกรรมขุดถ่านหิน อาชีพคนขุดถ่านหิน และสิ่งปลูกสร้างอุตสาหกรรม 5 แบบ
- เพิ่มสายวิจัยอุตสาหกรรม 8 งาน และวิจัยต่อยอด 2 แบบ ระดับสูงสุด 5
- เพิ่มโรงถลุงเหล็กกล้า เครื่องกำเนิดไอน้ำ และโรงงานเครื่องจักร
- เพิ่มโครงข่ายไฟฟ้าแบบไม่เก็บสะสม กำลังไฟต้องพอเต็มจำนวนจึงเปิดโรงงานได้
- เพิ่มลำดับไฟโรงงาน 3 ระดับ เมื่อไฟไม่พอจะหยุดโรงงานลำดับต่ำก่อน
- เพิ่มเงื่อนไขจบยุค: โรงงานอุตสาหกรรมครบ 3 แบบ เหล็กกล้า 100 เครื่องจักร 100 และวิจัยระบบโรงงานอัตโนมัติ
- เพิ่มการย้ายเซฟอัตโนมัติจาก schema v1/v2 เป็น v3
- เพิ่ม Hero ยุคอุตสาหกรรมและ UI ภาษาไทย/อังกฤษสำหรับระบบใหม่

## สมดุลเริ่มต้น

- คนขุดถ่านหิน: 0.25 ถ่านหิน/วินาที
- โรงถลุงเหล็กกล้า: ใช้เหล็ก 0.4 และถ่านหิน 0.2 ผลิตเหล็กกล้า 0.25/วินาที
- เครื่องกำเนิดไอน้ำ: ใช้ถ่านหิน 0.3 ผลิตกำลังไฟ 2 ต่อระดับ
- โรงงานเครื่องจักร: ใช้เหล็กกล้า 0.25 และกำลังไฟ 1 ผลิตเครื่องจักร 0.15/วินาที
- สถานีไฟฟ้าเพิ่มกำลังผลิตไฟ 5% ต่อหลัง
- วิจัยเครื่องกำเนิดประสิทธิภาพสูงเพิ่มกำลังผลิตไฟ 25%
